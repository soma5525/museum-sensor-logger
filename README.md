# 博物館センサ記録

公開URL：https://soma5525.github.io/museum-sensor-logger/

国立科学博物館（20地点）、神奈川県立生命の星・地球博物館（10地点）、東京国立博物館（10地点）の通過時刻を記録するWebアプリです。

## スマホで使う

1. 公開URLをiPhoneのSafari、またはAndroidのChromeで開きます。
2. iPhoneは共有メニューの「ホーム画面に追加」、Androidはメニューの「アプリをインストール」または「ホーム画面に追加」を選びます。
3. 追加したアイコンから、通信できる状態で一度起動します。画面下の「オフライン準備完了」を確認してください。
4. 施設・記録者・使用デバイスを設定します。デバイスは複数選択できます。BLE発信は別アプリで設定し、このアプリには同じ名前を入力します。
5. センサのA/Bボタンをタップして記録します。連打も別の記録として保存されます。
6. 実験後に「CSVを共有」または「CSVを保存」で回収します。

ホーム画面からの起動は全画面表示になります。初回のオフライン準備後は通信のない場所でも起動・記録できます。ブラウザによるキャッシュ削除後は、再度オンラインで開いて準備してください。

## 保存とCSV

- 記録は各端末のlocalStorageに保存します。サーバ同期、アクセス解析、記録の自動送信はありません。
- 同じ端末でもブラウザ・プロファイル・ホーム画面アプリ・URLを切り替えると保存領域が異なる場合があります。実験中は同じ起動方法を使ってください。
- 開発用URLの記録は公開URLへ自動移行されません。切り替える前にCSVを書き出してください。
- ブラウザのデータ消去、プライベートブラウズ、アプリ削除等によるデータ消失に備え、実験後に必ずCSVを回収してください。
- 同じ保存領域を複数タブで同時操作せず、記録は1画面で行ってください。
- 端末の日時を自動設定にしてください。時刻は端末の時計に依存し、履歴では変更できません。
- 履歴で変更できるのはセンサ番号と方向だけです。削除には確認があります。
- CSVにはそのブラウザの全施設・全記録者の記録を出力します。1イベントを1デバイス1行に展開し、同一record_idで紐付けます。

列：record_id, collector, device_name, device_type, timestamp, timestamp_ms, facility, sensor_number, direction

timestampはタイムゾーン付き秒単位、timestamp_msはUnix epochミリ秒です。MACアドレスは端末内の記録に保持し、CSVには含めません。

## 設定変更

room_logger.html の FACILITIES にある sensorCount を変更するとセンサを追加できます。科博・東博は仮番号、生命の星・地球博物館は設置図の1〜10をそのまま使います。

アプリを更新するときは sw.js の CACHE_NAME の版番号（v1など）も上げてください。開いている画面への強制更新はせず、アプリの全画面を閉じた後の次回起動時に新しい版を使用します。localStorageの保存キーは更新時も維持してください。

## Macで開発・確認

このリポジトリで次を実行します。

```sh
python3 -m http.server 8765 --bind 0.0.0.0
```

Macでは http://localhost:8765/ を、同じWi-Fiのスマホでは http://MacのLAN内IP:8765/ を開きます。作業終了時はCtrl+Cで停止してください。

LAN内のHTTP接続で記録UIは確認できますが、Service Workerによるオフライン起動はHTTPSの公開URLで確認してください。Macのlocalhostは開発用の例外として利用できます。

## テスト

Node.js 22以降を使用します。依存ライブラリは開発・テスト用であり、公開アプリは外部ライブラリを読み込みません。

```sh
npm ci
npm test
```

アイコンを変更する場合は icons/icon.svg を編集して npm run icons を実行します。

## GitHub Pages

Settings → Pages → Deploy from a branch → main / (root) を指定します。mainへpushすると更新が公開されます。.nojekyllにより静的ファイルをそのまま配信します。

サイトとソースコードは公開されますが、実験記録はリポジトリに含めません。CSVは.gitignoreの対象です。端末内のデータはHTTPSでもGitHubへ送信されません。
